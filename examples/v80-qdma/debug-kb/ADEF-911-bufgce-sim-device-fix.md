# ADEF-911 DRC Failure: BUFGCE SIM_DEVICE Mismatch

## Date: 2026-08-05

## Bug ID: ADEF-911

## Symptom
Vivado `write_device_image` step fails with DRC error ADEF-911. BUFGCE cells
generated by FIRRTL have `SIM_DEVICE=ULTRASCALE` but Versal HBM requires
`VERSAL_HBM`.

## Root Cause
1. **Checkpoint persistence**: `post_synth.tcl` fixes `SIM_DEVICE` in memory
   after opening the synthesis run, but `launch_runs` re-opens from the on-disk
   checkpoint where the fix isn't saved.
2. **Hook timing**: The `WRITE_DEVICE_IMAGE.TCL.PRE` hook (which downgrades
   ADEF-911 to a warning) was set AFTER the first `launch_runs` completed.
   Vivado 2025.1 doesn't retroactively apply it to the spawned subprocess.

## Fix (Belt-and-Suspenders)

### Prong A: Move TCL.PRE hook earlier (implementation.tcl)
Moved `set_property STEPS.WRITE_DEVICE_IMAGE.TCL.PRE` to BEFORE the first
`launch_runs` call (right after `reset_runs` and `set_property -dict` block).
This ensures the DRC downgrade hook is part of the initial run configuration
for all `launch_runs` invocations.

### Prong B: Fix BUFGCEs in synthesis subprocess (synthesis.tcl + post_synth_in_context.tcl)
- Created `post_synth_in_context.tcl` containing:
  ```tcl
  foreach cell [get_cells -hierarchical -filter {REF_NAME == BUFGCE} -quiet] {
      set_property SIM_DEVICE VERSAL_HBM $cell
  }
  ```
- Added `STEPS.SYNTH_DESIGN.TCL.POST` hook in `synthesis.tcl` pointing to this
  script, set before `launch_runs`. This runs inside the synthesis subprocess
  before the checkpoint is written to disk.

## Files Modified
- `$FIRESIM/platforms/xilinx_alveo_v80/cl_firesim/scripts/implementation.tcl`
- `$FIRESIM/platforms/xilinx_alveo_v80/cl_firesim/scripts/synthesis.tcl`
- `$FIRESIM/platforms/xilinx_alveo_v80/cl_firesim/scripts/post_synth_in_context.tcl` (new)

## Why Belt-and-Suspenders
- **Prong B** (TCL.POST) is the primary fix: BUFGCEs are corrected in the
  persistent checkpoint so downstream steps see the right value.
- **Prong A** (TCL.PRE) is the safety net: if any BUFGCE somehow slips through,
  the DRC check is downgraded to a warning instead of failing the build.
